Performance & Input Latency

Configure switch debounce filtering, NKRO rollover mode, and USB polling rate

Debounce Engine / Algorithm Symmetric Defer (QMK Default)

Choose the matrix switch scanning algorithm. Asymmetric Eager activates immediately upon press (0 ms actuation lag) while filtering release chatter; Symmetric Defer ensures maximum contact stability for typing.

Debounce Time / Filtering Window 5 ms

Filters mechanical contact vibrations (switch chatter). 0–2 ms offers ultra-fast esports response; 16 ms provides safe operation preventing accidental double clicks on older switches.

QMK Firmware is open-source software licensed under GPLv2+. VIA is an open configuration protocol standard.
